# Workspace

This repository contains two projects:

| Project | Path | Description |
|---------|------|-------------|
| Test Game | `/` (root) | Tile-based game prototype (React + Vite) |
| **Story Architecture Studio** | [`story-architecture-studio/`](./story-architecture-studio/) | Local-first narrative knowledge graph and comic planning tool |

## Story Architecture Studio

```bash
cd story-architecture-studio
npm install
npm run dev
```

See [story-architecture-studio/README.md](./story-architecture-studio/README.md) and [STATUS.md](./story-architecture-studio/STATUS.md) for details.
