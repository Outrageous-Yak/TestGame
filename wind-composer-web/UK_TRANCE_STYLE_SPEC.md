# UK Trance Style Spec

Reference: euphoric UK trance (e.g. JP-8000 supersaw, rolling offbeat bass, ~138–142 BPM).

## Identity

- Four-on-the-floor kick
- 16th hi-hats
- Rolling offbeat bassline (16-step sequencer)
- Euphoric supersaw lead hooks
- Pads restrained; lead is foreground
- Build → drop arrangement

## Tempo

- Range: 134–146 BPM
- Preferred: 138–142 BPM

## Bass families

| Family | Use |
|--------|-----|
| `rolling` | Default groove — offbeat 16ths |
| `rolling_fifth` | Drop / variation |
| `pump` | Build tension |
| `breakdown` | Sparse root |

## Lead

- `TranceLeadEngine` — repeating 4–6 note hooks with rising/arch contours
- Worklet `supersaw` preset — 5 detuned saw oscillators

## Settings

1. Style: **UK Trance**
2. Groove strength: **Strong**
3. Variation: **Evolving**
4. Dance & drums: **ON**
5. Weather influence: **Balanced** or **Strong**

## Listening test

Within 60 seconds you should hear: steady kick, rolling bass, 16th hats, and a recognizable supersaw motif in drop sections.
